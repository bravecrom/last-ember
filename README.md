# 마지막 불씨 (The Last Ember)

랜턴을 든 아이 **루미**가 쉰 해 전에 꺼진 **별등대**에 불씨를 올려놓기 위해 탑을 오르는 2D 점프 플랫포머입니다.
스페이스를 누르고 있다가 떼는 **차지 점프**로 오르고, 뛰어오른 뒤에도 ← →로 공중에서 움직일 수 있습니다(이야기 모드). 실수하면 아래 화면까지 떨어집니다.

- 5개 구역, 21개 화면: 잠든 숲(4) → 무너진 성벽(5) → 서리 동굴(4) → 바람의 첨탑(5) → 별등대(3)
  - 구역마다 마지막 화면은 그 구역 장애물을 모두 섞은 **시험 화면**이고, 별등대의 두 번째 화면은 돌풍·얼음·승강 발판·무너지는 돌이 모두 나오는 마지막 시험입니다
  - **추락 설계**: 구역 첫 화면과 중간 화면 바닥에 올라오는 구멍만 뚫린 받침이 있어, 보통 실수는 한 화면 안쪽에서 멈춥니다. 대신 구역마다 한두 곳(주로 시험 화면)은 받침 구멍으로 빠져 여러 화면을 떨어지는 **악명 지점**입니다
- **모드** (새로 시작에서 고름, 기록은 갈래마다 따로)
  - **이야기 모드**: 공중에서 ← →로 몸을 틀 수 있습니다
  - **등불지기 모드**: 공중 조작이 없습니다. 뛰는 순간 궤적이 정해집니다 (차지 점프 장르의 정통 방식)
  - **꺼진 탑** (한 번 오르면 열림): 쉰 해 전 등대가 꺼진 밤의 탑. 더 어둡고(랜턴 불빛이 덜 닿음), 바람이 1.3배 세고, 지도의 `K` 돌이 무너지는 돌이 됩니다. 인트로·엔딩이 따로 있습니다
- 구역마다 새 장애물이 나옵니다
  - **움직이는 발판** (숲·성벽·동굴·첨탑·별등대): 위에서 내려앉아 타고 가다 알맞은 때에 뛰어야 합니다. 점선이 발판이 오가는 길입니다. 뛰면 발판의 속도를 이어받습니다.
  - **무너지는 돌** (성벽·동굴): 밟으면 흔들리다가 약 0.7초 뒤 무너지고, 3초 뒤 다시 생깁니다.
  - **얼음** (동굴): 내려선 뒤에도 미끄러집니다.
  - **돌풍** (첨탑): 바람이 약 2초 불고 1.5초 쉽니다. 깃발이 늘어지면 바람이 멎은 것입니다.
  - 좁은 발판(2칸·1칸), 머리 위를 막는 낮은 천장
- 할머니의 기록이 새겨진 기억의 돌 5개, 까마귀 코르와의 대화 3번, 엔딩
- **불티 5개**: 구역마다 하나씩, 정해진 길에서 벗어난 아슬아슬한 곳(대개 허공)에 숨어 있습니다. 대신 크게 떨어질 각오를 해야 합니다. 하나 모을 때마다 랜턴 불빛이 조금씩 멀리 닿고, 다섯 개를 모두 모아 오르면 엔딩이 달라집니다.
- **화면 정보(HUD)**: 왼쪽 위에 점프·추락 횟수, 시간, 모은 불티. 오른쪽 가장자리의 높이 막대에 지금 높이(점)와 최고 높이(금색 눈금)
- **추락 표시**: 4.5m 넘게 떨어지면 잃은 높이(예: −24.1m)가 뜨고, 가장 긴 추락이 기록됩니다
- **추락 한마디**: 한 화면(9m) 넘게 떨어지면 루미나 까마귀 코르가 한마디 합니다 (30초에 한 번까지, 코르는 만난 뒤부터). 서리 동굴·바람의 첨탑에서 떨어지면 그곳 전용 대사가 섞여 나오고, 다른 구역까지 떨어지면 내려앉은 구역의 대사가 먼저 나옵니다. 대사는 `src/levels.js`의 `FALL_LINES`
- **떨어진 날의 기록**: 한 번 오르는 동안 엎어진 횟수가 5·15·30·60·100번에 닿으면 할머니의 기록이 하나씩 열립니다 (`FALL_MEMORIES`)
- **추락 다시 보기**: 한 화면 넘게 떨어지면 5초 동안 위에 "R 다시 보기"가 뜹니다. 뛰기 1초 전부터 착지까지 다시 보여 주고, 다시 보는 중에 C를 누르면 그 장면을 영상(webm)으로 저장합니다 (소리는 담기지 않음)
- **고스트**: 갈래마다 가장 빠른 오르기가 입력 기록으로 남고, 다음 오르기에서 반투명한 푸른 루미로 함께 오릅니다. 높이 막대에는 푸른 점으로 보입니다 (설정에서 끄기)
- **구간 기록**: 구역에 처음 들어설 때 그 시각과 최고 기록과의 차이(초록 = 빠름, 빨강 = 느림)가 구역 이름 아래에 뜹니다
- **업적 13개**, **랜턴 실 6가닥**(기본 붉은 실 + 구역마다 숨은 실 하나, 지도의 `t`. 감으면 랜턴 손잡이 색과 불빛 색이 바뀜) — 타이틀 → 기록 · 꾸미기
- **연습** (한 번 오르면 열림): 21개 화면 중 하나를 골라 그 화면 바닥에서 시작합니다. 기록·업적은 남지 않습니다
- **커스텀 맵**: 아래 "커스텀 맵 만들기" 참고
- **방송용 추락 카운터** (설정): 추락 수·잃은 높이·가장 긴 추락을 크게 보여 주고 떨어질 때마다 붉게 번쩍입니다
- **결과 카드**: 엔딩 뒤 기록 화면에서 C(패드 X)를 누르면 공유용 이미지(1200×630)를 저장합니다
- **게임패드**: 스틱·십자키 이동, A 점프·선택, Y 다시 읽기, X 추락 다시 보기·영상·결과 카드 저장, Start 일시정지, B 뒤로(메뉴·대화)
- **기록**: 갈래(탑 × 조작)마다 가장 빠른 시간, 가장 적은 점프 수, 가장 많이 모은 불티. 타이틀과 엔딩 화면에 나오고, 깨면 "신기록!", 못 깨면 최고 기록과의 차이가 붙습니다
- **배경음악**: 타이틀·다섯 구역·엔딩마다 다른 곡(코드로 작곡). 구역이 바뀌면 자연스럽게 넘어갑니다
- **설정** (타이틀 또는 Esc → 설정): 배경음악 크기, 효과음 크기(10% 단위), 화면 정보, 고스트, 방송용 추락 카운터 켜고 끄기, 전체 화면. 설정은 저장됩니다
- 그래픽·음악·효과음은 모두 코드로 생성 (이미지·음원 파일 없음)
- 서 있을 때 3초마다 자동 저장 → 타이틀에서 "이어하기" (연습·커스텀 맵은 저장하지 않음). 탑이 21개 화면으로 바뀌면서 저장 키가 `v2`가 되어, 예전 버전의 이어하기·기록은 읽지 않습니다

## 조작법

| 키 | 동작 |
|---|---|
| ← → (또는 A D) | 걷기 · 뛸 방향 고르기 · 공중에서 움직이기 |
| 스페이스 | 누르고 있다가 떼면 점프 (오래 누를수록 높이, 최대에 닿으면 자동으로 뜀) |
| ↑ (또는 W) | 기억의 돌 다시 읽기 · 까마귀와 다시 대화 |
| R | 크게 떨어진 직후: 그 장면 다시 보기 (다시 보는 중 C: 영상 저장) |
| C | 엔딩 뒤 기록 화면: 결과 카드 이미지 저장 |
| Enter / 스페이스 | 대화 넘기기 · 메뉴 선택 |
| Esc | 일시정지 (설정·조작법) |
| M / F | 소리 켜고 끄기 / 전체 화면 |

게임패드(표준 배치)도 됩니다: 스틱·십자키 = 방향키, A = 스페이스, Y = ↑, X = R·C, Start = Esc, B = 메뉴·대화에서 뒤로.

**휴대폰·태블릿**: 브라우저(웹판)에서 열면 터치 기기인지 알아서 판단해 화면 버튼을 띄웁니다. 화면을 만지면 버튼이 나타나고, 키보드를 누르면 사라집니다.

| 버튼 | 동작 |
|---|---|
| ◀ ▶ (왼쪽 아래) | 걷기 · 공중에서 움직이기 (손가락을 미끄러뜨려 방향 바꾸기) |
| 점프 (오른쪽 아래) | 누르고 있다가 떼면 점프. 테두리가 차오르며 힘을 보여 줍니다 |
| 머리 위 "눌러서 다시 읽기" | 기억의 돌·까마귀 곁에 있을 때 나타나는 글자를 누르면 다시 읽기 · 대화 |
| 위 "눌러서 다시 보기" | 크게 떨어진 직후 그 장면 다시 보기 (다시 보는 중 오른쪽 아래를 누르면 영상 저장) |
| ❚❚ (위 가운데) | 일시정지 |
| 화면 누르기 | 메뉴 항목 고르기 · 대화 넘기기 · 설정 막대 왼쪽/오른쪽으로 크기 조절 |

가로로 들면 버튼이 게임 화면 위에 겹치고, 세로로 들면 게임 화면이 위로 올라가고 버튼은 아래 빈 곳에 놓입니다.
아이폰 사파리처럼 전체 화면을 지원하지 않는 브라우저에서는 설정의 "전체 화면" 항목이 숨겨집니다. 홈 화면에 추가하면 주소창 없이 열립니다.

공중에서 벽에 부딪히면 반대로 튕겨 나오고, 높은 곳에서 떨어지면 잠깐 엎어집니다.
공중 이동의 세기는 `src/physics.js`의 `AIR_ACCEL`(가속)과 `AIR_MAX`(최고 속도)로 조절합니다. 등불지기 모드는 `setRules({ air: false })`로 `AIR_ACCEL`을 0으로 만든 것입니다.

## 맵 고치기

맵은 `src/levels.js`에 글자 그림으로 들어 있습니다. 한 화면은 32칸 × 18줄이고 `SCREENS[0]`이 맨 아래 화면입니다.

| 기호 | 뜻 | 기호 | 뜻 |
|---|---|---|---|
| `#` | 바위·벽 | `I` | 얼음 (미끄러움) |
| `C` | 무너지는 돌 | `S` | 기억의 돌 |
| `N` | 까마귀 코르 | `L` | 등불 (장식) |
| `f` | 깃발 (바람 방향 표시) | `P` | 시작 위치 |
| `G` | 별등대 (닿으면 엔딩) | `*` | 불티 (모으는 아이템, 공중에 둬도 됨) |
| `K` | 보통 탑에서는 바위, 꺼진 탑에서는 무너지는 돌 | `t` | 랜턴 실 (그 화면 구역의 실, 보통 탑에서만 보임) |

화면마다 넣을 수 있는 설정입니다.

- `wind`: 공중에 있는 동안 그 방향으로 밀립니다 (양수 →, 음수 ←).
- `gust: true`: 바람이 240프레임 주기로 불다가 쉽니다.
- `movers`: 움직이는 발판 목록. `{ col, row, w, dx, dy, period, phase }` — (col,row)에서 (col+dx,row+dy)까지 칸 단위로 부드럽게 왕복합니다. `period`(주기, 프레임)는 240의 약수여야 합니다.

무너지는 돌이 버티는 시간과 다시 생기는 시간은 `src/physics.js`의 `CRUMBLE_DELAY`, `CRUMBLE_RESPAWN`입니다.

맵을 고친 뒤에는 검증기로 끝까지 오를 수 있는지 확인하세요. 게임과 같은 물리 코드로 가능한 점프를 모두 시뮬레이션합니다.
움직이는 발판·돌풍이 있는 곳은 출발 시각을 바꿔 가며, 무너지는 돌 위에서는 남은 시간 안에 뛸 수 있는지까지 따집니다.
도달 가능한 발판(`^`)과 불가능한 발판(`x`), 불티·랜턴 실을 모두 모을 수 있는지, 가장 쉬운 경로에서 각 이동이 얼마나 어려운지(성공하는 조합 수) 보여 줍니다. 탑 전체는 3~5분 걸립니다.

```bash
npm run validate
```

등불지기 모드에서 오를 수 있으면 이야기 모드에서도 오를 수 있습니다 (공중 조작을 쓰지 않는 점프가 같으므로). 맵을 고치면 적어도 아래 두 가지는 통과해야 합니다.

```bash
node tools/validate-levels.js -q --keeper
```

```bash
node tools/validate-levels.js -q --keeper --dark
```

`--falls`를 붙이면 **추락 지도**가 나옵니다. 가장 쉬운 경로의 점프마다 차지를 ±3프레임(약 0.05초) 빗나가게 뛰었을 때, 몇 %가 떨어지고 평균·최악으로 몇 m를 잃는지, 최악이면 어디에 떨어지는지 보여 줍니다. 마지막에 화면별 요약이 붙습니다.

```bash
node tools/validate-levels.js -q --keeper --falls
```

## 커스텀 맵 만들기

1. 기본 탑을 견본으로 내보냅니다: `node tools/validate-levels.js --export my-map.json`
2. `my-map.json`의 `name`, `author`, `screens`를 고칩니다. `screens`는 위 "맵 고치기"와 같은 형식(맨 아래 화면부터)이고 `P`와 `G`가 하나씩 있어야 합니다. 기억의 돌·까마귀 글은 없어도 됩니다
3. 검증하고 통과하면 파일에 검증 표시를 씁니다. 두 모드 모두 통과시키면 게임에 "검증됨 (이야기·등불지기)"로 나옵니다

```bash
node tools/validate-levels.js -q --map my-map.json --stamp
```

```bash
node tools/validate-levels.js -q --keeper --map my-map.json --stamp
```

4. 게임에서 타이틀 → 도전 → 커스텀 맵 → 맵 파일 열기 (또는 타이틀 화면에 파일을 끌어다 놓기). 맵을 고치면 지문이 달라져 검증 표시가 풀립니다

커스텀 맵은 저장·업적이 없고, 맵마다 가장 빠른 시간만 남습니다.

## 플레이테스트 통계

기본 탑을 오르는 동안 기기 안에 화면별 머문 시간·점프·엎어짐, 큰 추락의 출발→착지 화면, 그만둔 화면, 클리어 시간이 쌓입니다 (밖으로 보내지 않음).
테스터에게 타이틀 → 기록 · 꾸미기 → **통계 내보내기**로 파일을 받아 모아 보면, 어느 화면에서 오래 막히고 어디서 그만두는지 보입니다.

```bash
node tools/telemetry-report.js 철수.json 영희.json
```
