# 마지막 불씨 (The Last Ember)

랜턴을 든 아이 **루미**가 쉰 해 전에 꺼진 **별등대**에 불씨를 올려놓기 위해 탑을 오르는 2D 점프 플랫포머입니다.
스페이스를 누르고 있다가 떼는 **차지 점프**로 오르고, 뛰어오른 뒤에도 ← →로 공중에서 움직일 수 있습니다. 실수하면 아래 화면까지 떨어집니다.

- 5개 구역, 12개 화면: 잠든 숲 → 무너진 성벽 → 서리 동굴 → 바람의 첨탑 → 별등대
- 구역마다 새 장애물이 나옵니다
  - **움직이는 발판** (숲·성벽·동굴·첨탑·별등대): 위에서 내려앉아 타고 가다 알맞은 때에 뛰어야 합니다. 점선이 발판이 오가는 길입니다. 뛰면 발판의 속도를 이어받습니다.
  - **무너지는 돌** (성벽·동굴): 밟으면 흔들리다가 약 0.7초 뒤 무너지고, 3초 뒤 다시 생깁니다.
  - **얼음** (동굴): 내려선 뒤에도 미끄러집니다.
  - **돌풍** (첨탑): 바람이 약 2초 불고 1.5초 쉽니다. 깃발이 늘어지면 바람이 멎은 것입니다.
  - 좁은 발판(2칸·1칸), 머리 위를 막는 낮은 천장
- 할머니의 기록이 새겨진 기억의 돌 5개, 까마귀 코르와의 대화 3번, 엔딩
- **불티 5개**: 구역마다 하나씩, 정해진 길에서 벗어난 아슬아슬한 곳(대개 허공)에 숨어 있습니다. 대신 크게 떨어질 각오를 해야 합니다.
- **화면 정보(HUD)**: 왼쪽 위에 점프·추락 횟수, 시간, 모은 불티. 오른쪽 가장자리의 높이 막대에 지금 높이(점)와 최고 높이(금색 눈금)
- **추락 표시**: 4.5m 넘게 떨어지면 잃은 높이(예: −24.1m)가 뜨고, 가장 긴 추락이 기록됩니다
- **추락 한마디**: 한 화면(9m) 넘게 떨어지면 루미나 까마귀 코르가 한마디 합니다 (30초에 한 번까지, 코르는 만난 뒤부터). 대사는 `src/levels.js`의 `FALL_LINES`
- **게임패드**: 스틱·십자키 이동, A 점프·선택, Y 다시 읽기, Start 일시정지, B 뒤로(메뉴·대화)
- **기록**: 가장 빠른 시간, 가장 적은 점프 수, 가장 많이 모은 불티. 타이틀과 엔딩 화면에 나오고, 깨면 "신기록!"이 붙습니다
- **배경음악**: 타이틀·다섯 구역·엔딩마다 다른 곡(코드로 작곡). 구역이 바뀌면 자연스럽게 넘어갑니다
- **설정** (타이틀 또는 Esc → 설정): 배경음악 크기, 효과음 크기(10% 단위), 화면 정보 켜고 끄기, 전체 화면. 설정은 저장됩니다
- 그래픽·음악·효과음은 모두 코드로 생성 (이미지·음원 파일 없음)
- 서 있을 때마다 자동 저장 → 타이틀에서 "이어하기"

## 조작법

| 키 | 동작 |
|---|---|
| ← → (또는 A D) | 걷기 · 뛸 방향 고르기 · 공중에서 움직이기 |
| 스페이스 | 누르고 있다가 떼면 점프 (오래 누를수록 높이, 최대에 닿으면 자동으로 뜀) |
| ↑ (또는 W) | 기억의 돌 다시 읽기 · 까마귀와 다시 대화 |
| Enter / 스페이스 | 대화 넘기기 · 메뉴 선택 |
| Esc | 일시정지 (설정·조작법) |
| M / F | 소리 켜고 끄기 / 전체 화면 |

게임패드(표준 배치)도 됩니다: 스틱·십자키 = 방향키, A = 스페이스, Y = ↑, Start = Esc, B = 메뉴·대화에서 뒤로.

**휴대폰·태블릿**: 브라우저(웹판)에서 열면 터치 기기인지 알아서 판단해 화면 버튼을 띄웁니다. 화면을 만지면 버튼이 나타나고, 키보드를 누르면 사라집니다.

| 버튼 | 동작 |
|---|---|
| ◀ ▶ (왼쪽 아래) | 걷기 · 공중에서 움직이기 (손가락을 미끄러뜨려 방향 바꾸기) |
| 점프 (오른쪽 아래) | 누르고 있다가 떼면 점프. 테두리가 차오르며 힘을 보여 줍니다 |
| 머리 위 "눌러서 다시 읽기" | 기억의 돌·까마귀 곁에 있을 때 나타나는 글자를 누르면 다시 읽기 · 대화 |
| ❚❚ (위 가운데) | 일시정지 |
| 화면 누르기 | 메뉴 항목 고르기 · 대화 넘기기 · 설정 막대 왼쪽/오른쪽으로 크기 조절 |

가로로 들면 버튼이 게임 화면 위에 겹치고, 세로로 들면 게임 화면이 위로 올라가고 버튼은 아래 빈 곳에 놓입니다.
아이폰 사파리처럼 전체 화면을 지원하지 않는 브라우저에서는 설정의 "전체 화면" 항목이 숨겨집니다. 홈 화면에 추가하면 주소창 없이 열립니다.

공중에서 벽에 부딪히면 반대로 튕겨 나오고, 높은 곳에서 떨어지면 잠깐 엎어집니다.
공중 이동의 세기는 `src/physics.js`의 `AIR_ACCEL`(가속)과 `AIR_MAX`(최고 속도)로 조절합니다. `AIR_ACCEL`을 0으로 하면 공중 조작이 없는 원래 방식이 됩니다.

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

## 맥 · 윈도우용 앱 만들기

```bash
npm run dist:mac
```

```bash
npm run dist:win
```

```bash
npm run dist:web
```

결과물은 `dist/` 폴더에 생기고, 빌드가 끝나면 플랫폼마다 올리기 좋은 zip도 함께 만들어집니다 (`tools/dist.js`, 맥에서만).

| 판 | 폴더 | zip |
|---|---|---|
| 맥 (애플 실리콘) | 약 257MB | 약 115MB |
| 맥 (인텔) | 약 263MB | 약 121MB |
| 윈도우 | 약 309MB (언어팩 정리로 −48MB) | 약 139MB |
| 웹 (itch.io 등) | 약 128KB | 약 42KB |

- 윈도우판은 Chromium 언어팩 중 한국어·영어만 남깁니다. 게임 글자는 캔버스로 그리므로 영향이 없습니다.
- 웹판(`dist/LastEmber-web.zip`)은 itch.io에 "HTML" 게임으로 그대로 올릴 수 있습니다. 앱 크기의 거의 전부는 Electron(Chromium) 자체입니다.

- 맥: `dist/LastEmber-darwin-arm64/LastEmber.app` (애플 실리콘), `dist/LastEmber-darwin-x64/LastEmber.app` (인텔)
- 윈도우: `dist/LastEmber-win32-x64/` 폴더 전체를 윈도우 PC로 옮긴 뒤 `LastEmber.exe` 실행

맥에서 윈도우용도 함께 빌드됩니다 (Wine 불필요). 코드 서명을 하지 않은 앱이라, 다른 컴퓨터에서 처음 열 때
맥은 "확인되지 않은 개발자" 경고가 뜨면 앱을 **우클릭 → 열기**, 윈도우는 SmartScreen 창에서 **추가 정보 → 실행**을 누르면 됩니다.

## 맵 고치기

맵은 `src/levels.js`에 글자 그림으로 들어 있습니다. 한 화면은 32칸 × 18줄이고 `SCREENS[0]`이 맨 아래 화면입니다.

| 기호 | 뜻 | 기호 | 뜻 |
|---|---|---|---|
| `#` | 바위·벽 | `I` | 얼음 (미끄러움) |
| `C` | 무너지는 돌 | `S` | 기억의 돌 |
| `N` | 까마귀 코르 | `L` | 등불 (장식) |
| `f` | 깃발 (바람 방향 표시) | `P` | 시작 위치 |
| `G` | 별등대 (닿으면 엔딩) | `*` | 불티 (모으는 아이템, 공중에 둬도 됨) |

화면마다 넣을 수 있는 설정입니다.

- `wind`: 공중에 있는 동안 그 방향으로 밀립니다 (양수 →, 음수 ←).
- `gust: true`: 바람이 240프레임 주기로 불다가 쉽니다.
- `movers`: 움직이는 발판 목록. `{ col, row, w, dx, dy, period, phase }` — (col,row)에서 (col+dx,row+dy)까지 칸 단위로 부드럽게 왕복합니다. `period`(주기, 프레임)는 240의 약수여야 합니다.

무너지는 돌이 버티는 시간과 다시 생기는 시간은 `src/physics.js`의 `CRUMBLE_DELAY`, `CRUMBLE_RESPAWN`입니다.

맵을 고친 뒤에는 검증기로 끝까지 오를 수 있는지 확인하세요. 게임과 같은 물리 코드로 가능한 점프를 모두 시뮬레이션합니다.
움직이는 발판·돌풍이 있는 곳은 출발 시각을 바꿔 가며, 무너지는 돌 위에서는 남은 시간 안에 뛸 수 있는지까지 따집니다.
도달 가능한 발판(`^`)과 불가능한 발판(`x`), 불티를 모두 모을 수 있는지, 가장 쉬운 경로에서 각 이동이 얼마나 어려운지(성공하는 조합 수) 보여 줍니다. 1~2분 걸립니다.

```bash
npm run validate
```

index.html               게임 페이지
main.js                  Electron 창

tools/validate-levels.js 레벨 검증기
